problem i faced 
=> Replicating the Figma layout precisely without using any SVG was challenging, especially the megaphone illustration and card icon clusters, which had to be built entirely with CSS shapes and HTML characters.
=> Matching the exact card color combinations (beige, green, dark) with correct text and arrow button colors for each variant took careful attention to the design reference.

What i learnt 
=> How to structure a multi-section landing page across separate HTML, CSS, and JS files in a clean, beginner-friendly way.
=> Using CSS `box-shadow` with no blur (e.g. `4px 4px 0 #191a23`) creates the bold flat-shadow card effect seen in modern UI designs like Positivus.
=> Creative use of HTML entities and CSS `border` tricks can replace SVG illustrations while keeping the code simple and lightweight.
